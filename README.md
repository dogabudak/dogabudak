## Selected public projects

### [btcturk_websockets](https://github.com/dogabudak/btcturk_websockets)

An asynchronous Rust library for working with BtcTurk WebSocket and REST APIs.  
Built with Tokio, Tungstenite, Reqwest and Serde.

### [Into the Light](https://github.com/dogabudak/the_game)

A 2D isometric roguelike and strategy game built with Godot. It explores procedural environments, party management, stealth, fog of war and base-building mechanics.

### [YeşilDoğa](https://github.com/dogabudak/yesil-ext)

A browser extension exploring how environmental and sustainability information can be presented while browsing the web.

### [CSV to JSON](https://github.com/dogabudak/csvtojson-ts)

A TypeScript project for converting and processing CSV data as structured JSON.
